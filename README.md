# Game with AI — Starter Pack

**Prompts that move: an Opus 5.5 field guide for games, art, animation, 3D and coded video.**

A single-page, self-contained guide to briefing Claude Opus 5.5 for creative builds — with live demos, starter prompts and checklists for every craft from art direction to performance.

**▶ Read it online:** https://2600th.github.io/game-with-ai-starter-pack/

## What's inside

- **Start here** — pick what you're making; the 60-second version; anatomy of a build brief
- **Playbooks by format** — games, animation, dioramas, 3D scenes, coded video
- **Engines and libraries** — choosing the right stack
- **Craft sections** — game design, art direction, illustration/SVG/generative art, 3D assets, asset generation, level design, game AI, procedural generation, physics and character controllers, camera systems, character animation, VFX, shaders and post-processing, sound and music from code, game juice, UI/HUD and accessibility
- **Coded video** — frameworks and determinism
- **Performance and profiling**
- **Working process** — iterating like a director, multi-session builds, the build contract, effort and long runs, which model to use
